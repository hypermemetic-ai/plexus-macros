# plexus-macros

#[activation]: a Rust module becomes a WebAssembly component, its WIT written from the code.

The module is read into an IR (`plexus-ir`); its WIT and TypeScript are written from the IR by `plexus-gen`.

Part of Plexus, built from scratch (tracker: LAYERS-9). Its sibling crates are expected beside it: `../<crate>`.
